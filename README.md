# 一起看 🎬

异地一起看视频。支持 **B站 / 腾讯视频 / 爱奇艺**，同步播放、暂停、拖进度，附带文字消息。

## 原理

视频各看各的（各自的浏览器直接播放，画质不打折、不卡）。
两个浏览器插件只通过一台 WebSocket 中转服务同步「播放/暂停/跳进度」这几个控制信号——传的是几十字节的 JSON，带宽几乎为零。

```
你的浏览器  ──控制信号──►  WebSocket 中转服务  ──控制信号──►  女朋友的浏览器
   (本地播放视频)                (只转发指令)                (本地播放视频)
```

## 一、部署中转服务到 Railway（一次性，约 10 分钟）

1. 把 `server/` 目录推到一个 GitHub 仓库。
2. 打开 https://railway.app ，用 GitHub 登录。
3. New Project → Deploy from GitHub repo → 选你的仓库。
   - 如果仓库根目录不是 server，在 Settings → Root Directory 填 `server`。
4. Railway 会自动 `npm install` 并 `node server.js`。
5. 部署好后进 Settings → Networking → **Generate Domain**，得到一个域名，
   比如 `watch-xxx.up.railway.app`。
6. 插件里要填的地址是 **wss://** 开头（注意不是 https）：
   ```
   wss://watch-xxx.up.railway.app
   ```

> Render 同理：New → Web Service → 选仓库 → Start Command 填 `node server.js`。

## 二、安装 Chrome 插件（你和女朋友各装一次）

1. Chrome 地址栏打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本项目的 `extension/` 文件夹
4. 把 `extension/` 文件夹发给女朋友，她也照做一遍

## 三、一起看

1. 两人打开**同一个**视频页面（同一集、同一个清晰度最好）。
2. 点浏览器右上角的「一起看」插件图标。
3. 两人填**相同**的：
   - 中转服务地址：`wss://watch-xxx.up.railway.app`
   - 房间号：随便约定一个，比如 `我俩的小屋`（两人必须一致）
   - 房间密码：约定一个，比如 `0520`（两人必须一致，留空则无密码）
4. 都点「加入房间」。看到「对方在线」就成了。

> 密码怎么起作用：服务端按「房间号 + 密码」一起区分房间。密码不对的人即使猜中房间号，
> 也会被分到另一个房间，收不到你们的同步消息。服务端不保存密码。
5. 之后谁按暂停/播放/拖进度，两边同步。想说话直接在插件里发消息，或者另开个微信语音挂着。

## 常见问题

- **进度差一点点**：网络有延迟，正常。差超过 0.8 秒会自动对齐。手动拖一下进度条即可强制同步。
- **换集/换清晰度后不同步**：播放器会重建 video 元素，插件每 2 秒自动重新绑定；若没跟上，任意一方拖一下进度条触发一次同步即可。
- **点了加入没反应**：确认当前页面是 B站/腾讯/爱奇艺的**视频播放页**，不是首页。
- **腾讯视频/爱奇艺的广告**：贴片广告期间 video 元素和正片不是同一个，等广告放完进正片再一起点播放最稳。
